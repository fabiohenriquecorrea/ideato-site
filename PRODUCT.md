# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router, TypeScript) as a static export on Cloudflare Pages (free). The /admin editor commits content/*.json to GitHub; Cloudflare rebuilds on push. No database, no server. Chosen by the user for cost.

## Users

Business owners and marketing leads from any segment (the studio serves many industries — do not frame the site around construction) evaluating a studio for brand, social media, aerial imagery and site. They arrive from Instagram (@ideatostudio), a proposal link or referral, and decide whether to start a conversation.

## Product Purpose

Portfolio site for Ideato Studio. Shows selected work and the studio's reasoning, and converts into a simple conversation (Instagram DM; e-mail/WhatsApp when configured). No long forms. Success = qualified contact requests.

## Positioning

"Da ideia ao ato." One studio, four fronts (Marca, Social, Imagem com drone, Site) driven by the same brand reasoning — every delivery is a considered decision, not a standalone product.

## Operating Context

Base: Maringá · PR. Responsável: Fabio Correa. Language must stay segment-neutral (no obra/construtora framing).

## Brand Commitments

Binding: Ideato Design System v1 (source: ~/Downloads/Ideato Design System.html). Tokens papel/tinta/lima/céu, Bounded variable font + IBM Plex Mono, square corners, 1px hairline grids, lima reserved for the single decision point. Voice: Portuguese (pt-BR), direct, confident, short declarative headlines.

## Product Principles

1. Reasoning before aesthetics — show the decision behind each delivery.
2. One idea across every front — marca, social, imagem and site speak the same language.
3. Simplicity — short paths to a conversation, no long forms.
4. Let the work lead; the interface recedes.
